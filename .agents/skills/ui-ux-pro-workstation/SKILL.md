# UI/UX Pro Workstation Directives
- Dark Slate theme (#0B0D13 base, #161922 panels, #272B35 borders).
- PC: 3-pane layout. Mouse wheel zoom centered on cursor, Space+Drag panning, shortcuts ([ / ] rotate, Shift+[ / ] even rotate, S split guide).
- Mobile: Fullscreen score viewer with slide-up Bottom Sheet drawer. @use-gesture/react for 2-finger pinch zoom and 1-finger swipe page navigation.
