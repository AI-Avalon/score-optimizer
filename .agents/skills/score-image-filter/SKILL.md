# Score Image Filter

スキャン画像の品質を最適化する。

## カラーモード
- **color (カラー保持)**: 元の色調をそのまま出力。
- **grayscale (グレースケール)**: モノクロ変換して出力（データサイズ削減）。
- **monochrome (二値化)**: 閾値を用いて白と黒の2値に変換。

## モノクロ二値化と裏写り消去
- 二値化閾値（0〜255）を設定可能にする。
- 背景の黄ばみや裏写りピクセル（輝度の高い中間調）を白（255）へ飛ばし、五線譜や符頭の黒（0）をシャープに残すこと。
- 適応型閾値あるいはピクセル走査による高解像度での処理を実装すること。
