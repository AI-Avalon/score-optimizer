# Canvas Workstation Directives
- Zoom HUD floating on top: `[ - ] [ 100% ] [ Fit ] [ + ]` displaying exact zoom %.
- Outer Green Box: Bounding box of content crop.
- Inner Orange Vertical Line: Spread split guide located inside the crop box, draggable horizontally.
- Bottom Filmstrip: Renders all page thumbnails reliably.
- Responsive: 100dvh, zero overflow-x on mobile (390px).
