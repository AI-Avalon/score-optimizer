# Score Batch Workflow

楽譜のインポートと一括処理を行う際のルール。

## 初期ウィザード
PDF読込時に以下の選択肢を提示し、ページの初期状態を一括設定すること。
- **[全見開き]**: すべてのページを `isSpread = true`, `skipSplit = false` とする。
- **[全単一]**: すべてのページを `isSpread = false` とする。
- **[表紙のみ単一＋見開き]**: 最初のページを `isSpread = true`, `skipSplit = true`、それ以降を `isSpread = true`, `skipSplit = false` とする。

## 状態分離と校正モード
- **全ページ一括設定**と**個別微調整**を分離する。
- ユーザーが「全ページ一括適用」を選択した場合、現在のページ設定（余白、色調、回転など）を後続あるいは全てのページにコピーする。
- キーボードの `←` `→` キーを用いて、インスペクター等のパネルを開いたまま素早く1ページずつ確認・微調整できる「全ページ通し校正モード」を実装すること。
